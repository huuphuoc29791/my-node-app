# RESTful API: Stateless

# HTTP Methods
- GET       /api/students: Get all students
- GET       /api/students/:id: Get student by ID
- POST      /api/students + JSON data: Create student
- PUT       /api/students/:id + JSON data: Update student (replace)
- PATCH     /api/students/:id + JSON data: Update student (update by property)
- DELETE    /api/students/:id: Delete student
